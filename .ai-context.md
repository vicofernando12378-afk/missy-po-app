## Decisiones Técnicas Tomadas

1. **Query Parameters en Detalle de Pedido:** Para mantener el sitio compilando de forma 100% estática en Astro sin requerir rewrites de hosting complejos o SSR, la vista de detalle del pedido consume el ID mediante query parameters (`detalle?id=XXXX`).
2. **Seguridad de Perfiles de Usuario:** Los perfiles se indexan mediante el UID del usuario (`myp_user_profiles/{userId}`). Se aplica validación estricta a nivel de reglas de seguridad Firestore para denegar accesos cruzados de datos de terceros.
